Proyecto de consultoría para construir la primera infraestructura de datos de una startup.

- Implementación de **BigQuery**, **Stitch** y **Looker Studio** como base de reporting
- Diseño del primer **pipeline de eventos** para transmitir datos a BigQuery
- Priorización de soluciones creativas y económicas adaptadas a escala startup
