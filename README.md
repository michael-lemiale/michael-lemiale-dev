# michael-lemiale-dev
[Personal portfolio site](https://www.michael-lemiale.dev)

Built with SvelteKit and Tailwind CSS.

## Site
https://www.michael-lemiale.dev

## Development

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production (includes PDF generation)
bun run build

# Preview production build
bun preview
```
